# 🏫 School Management System (C++)

## 📌 Description
This is a console-based School Management System built using C++.  
The system supports role-based access for Admin, Staff, and User.  
It allows management of students, teachers, results, and history logs using linked lists and file handling.

---

## ✨ Features

### 👑 Admin
- Add Student
- Delete Student
- Add Teacher
- View History
- View All Students

### 👨‍🏫 Staff
- search Student
- View Students
- View results


### 👤 User
- Search Student
- Print Result to File

---

## 🛠 Technologies Used
- C++
- Object-Oriented Programming (OOP)
- Inheritance & Polymorphism
- STL (vector, algorithm)
- File Handling
- Singly Linked List (Teacher Management)
- Doubly Linked List (History Tracking)
- Sorting & Binary Search

---

## 📁 Data Storage
- Students saved in `students.txt`
- Teachers saved in `teachers.txt`
- History saved in `history.txt`
